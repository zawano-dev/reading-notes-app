《頁間》v5.2.1｜私人筆記頁＋公開閱讀頁「回到頂端」

這次修改
- 私人《頁間》筆記長頁面：向下捲動超過約 320px 後，右下角顯示浮動「頂端」按鈕。
- 獨立公開閱讀頁：同樣顯示「頂端」按鈕。
- 點擊後平滑回到頁首；偏好減少動畫的使用者不會看到平滑動畫。
- 短頁面與頁首自動隱藏；手機也能使用。
- 私人頁面開啟新增／編輯對話框時，回頂端按鈕會隱藏，不遮住表單。
- 包含 v5.1.1「公開頁書名不自動加《》」修正。
- 其他功能不變：雲端同步、外連、粗體、底線、樹狀筆記目錄、單篇分享、左右鍵限制（僅公開閱讀頁）。

上傳 GitHub：
1. 解壓縮更新包。
2. 把解壓縮後以下 6 個檔案（保留路徑）拖到 GitHub 的 Upload files 頁面，取代同名檔案：
   index.html
   css/style.css
   js/app.js
   share.html
   css/share.css
   js/share.js
3. 按 Commit changes。
4. GitHub Pages 更新後，私人筆記頁與公開閱讀頁都往下捲動測試。

注意：沒有變動 js/config.js，也不需要執行 Supabase SQL。此更新只影響介面。
